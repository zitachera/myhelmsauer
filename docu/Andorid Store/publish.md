# App im PlayStore veröffentlichen

- Versions- und Buildnummer (hinterm plus) in `app/pubspec.yaml` erhöhen.
- Im Appverzeichnis `flutter build appbundle` ausführen.
- Neuen Release in [PlayConsole](https://play.google.com/console/u/1/developers/7530805488848502674/app/4975280733115741471/tracks/4697330640140660360?tab=releases) erstellen
- Upload von `app/build/app/outputs/bundle/release/app-release.aab`.
- Release freischalten.
